# SUPRA MAGNATE — мобильный симулятор магната 🏙💰

Полноценная мобильная игра-тайкун в духе тайкунов из Play Market: построена на чистом
HTML/CSS/JS (без зависимостей), весь арт — процедурный **SVG** + реальные **фото** (машины,
дома, яхта, джет). Устанавливается на телефон как PWA и работает офлайн.

## Как запустить

```bash
cd game
npm run serve        # http://localhost:8000  (или откройте index.html)
```

Откройте на телефоне адрес превью — добавьте на главный экран (PWA) и играйте офлайн.

## Что внутри

| Раздел | Фичи |
|---|---|
| 🏙 Империя | тап-монета с частицами, растущий SVG-город, работа (6 профессий), задания дня, буст x2, новости |
| 🏢 Бизнес | 16 бизнесов (от шаурмы до космической компании), уровни, множители-вехи x2/x3/x4…, менеджеры, покупка x1/x10/MAX |
| 🚗 Гараж | 5 тачек, 5 домов, 5 предметов роскоши с фото и постоянными бонусами к тапу/доходу/офлайну |
| 📈 Крипта | биржа (BTC, ETH, SUPRA, MEME, USDX) с живыми ценами, SVG-графиком, покупкой/продажей и стейкингом; майнинг-риги (BTC/сек); банк (вклад + кредит) |
| 👑 Профиль | уровни и статусы, престиж с алмазами, 16 достижений, ежедневка на 7 дней, рулетка, настройки, экспорт/импорт сейва |

Экономика: пассивный доход, офлайн-доход (до 100% с менеджерами), проценты банка,
случайные рыночные новости, которые двигают цены. Прогресс сохраняется автоматически
(`localStorage`), есть перенос сейва кодом.

## Структура

```
game/
  index.html            каркас приложения (HUD, вкладки, sheet, тосты)
  css/app.css           мобильный UI (тёмная тема, стекло, золото)
  js/economy.js         чистая игровая логика (без DOM) — покрыта тестами
  js/data.js            каталоги: бизнесы, тачки, дома, крипта, ачивки, работа
  js/art.js             SVG-арт: иконки, 20+ сцен, город, графики, рулетка
  js/state.js           сохранение/загрузка/миграции
  js/main.js            игровой цикл, экраны, события, звук, вибрация
  assets/img/           фото (jpg + webp)
  sw.js, manifest...    PWA: офлайн-кэш и установка на телефон
  tests/                юнит-тесты экономики + смоук всего UI (jsdom)
```
